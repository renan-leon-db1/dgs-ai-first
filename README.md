# DGS AI First - Entregas Tech Lead

## Descricao do repositorio
Este repositorio foi criado para armazenar as entregas da trilha AI First do cargo de Tech Lead.

As atividades praticas estao organizadas por cenario, e cada cenario fica em sua propria branch.

## Funcionamento
As entregas estao separadas nas seguintes branches:

- `cenario-1`
- `cenario-2`
- `cenario-3`

Cada branch contem os exercicios e artefatos correspondentes ao respectivo cenario.

## Como acessar cada cenario
1. Clone o repositorio:

```bash
git clone <url-do-repositorio>
cd dgs-ai-first
```

2. Liste as branches disponiveis:

```bash
git branch -a
```

3. Troque para a branch do cenario desejado:

```bash
git checkout cenario-1
# ou
git checkout cenario-2
# ou
git checkout cenario-3
```

## Boas praticas
- Mantenha cada exercicio no cenario correto.
- Evite misturar conteudo de cenarios diferentes na mesma branch.
- Use mensagens de commit claras para facilitar o historico das entregas.

## Observacao
A branch principal pode ser utilizada apenas para documentacao geral e orientacoes do repositorio.
